# License texts

The project license is [Apache-2.0](../LICENSE). These files preserve separate
third-party license texts; their presence does not apply each license to the
whole repository. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for
file/dependency scope and the outstanding firmware-binary release gate.

[provenance.json](provenance.json) records the source and SHA-256 of each copied
text. Existing font `assets/*OFL.txt` and component license files remain in place
so those components retain their notices when distributed separately.
